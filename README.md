### Private repositories

**IRC bots**

- [aibot](https://github.com/nukam0s/aibot) — Modular IRC AI bot (Python) with per-network user memory (JSON), channel-join retry handling and an auto-migration "memory hygiene" module.
- [espnbot](https://github.com/nukam0s/espnbot) — IRC betting bot over ESPN data, pickle-based betting DB, using curl_cffi Chrome TLS impersonation to bypass Akamai bot protection.
- [futcom](https://github.com/nukam0s/futcom) — IRC football match commentary/voting bot streaming ESPN soccer scoreboards; multithreaded with OpenAI integration and dynamic league auto-blacklist/backoff.
- [gulag](https://github.com/nukam0s/gulag) — Python IRC bot (channel #gulag on Undernet) with gag/mute management and user-activity/voter persistence.
- [idlegame](https://github.com/nukam0s/idlegame) — IdleGame: IRC idle/RPG bot in Python 3 (pydle + aiosqlite) with economy, items, pets, duels, raids, arena and quests across multiple networks; generates a static web ranking.
- [jupe](https://github.com/nukam0s/jupe) — IRC bot for #nuke (Undernet) enforcing nick priority/ownership via an ordered priority nick list and admin hostmasks.
- [la](https://github.com/nukam0s/la) — Python IRC protection bot with kick/ban-rate based "attack mode", DNSBL matching, rotating logs and OpenAI assistance.
- [newsbot](https://github.com/nukam0s/newsbot) — IRC news bot (pydle) that polls RSS feeds via feedparser and announces them across multiple command prefixes at a configurable interval.
- [pybot](https://github.com/nukam0s/pybot) — protbot.py — multi-instance IRC protection bot with badwords filtering (order-independent matching), blocklists, DNSBL, tempbans, user preferences and i18n (lang.py).
- [relaybot](https://github.com/nukam0s/relaybot) — IRC relay bot bridging multiple channels/networks, with a watchdog that refreshes the channel list each cycle and a JSON user registry.
